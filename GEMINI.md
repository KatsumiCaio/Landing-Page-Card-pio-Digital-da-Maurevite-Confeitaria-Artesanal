# Maurevite — Contexto de Projeto e Regras de Operação

Consulte o arquivo `/AGENTS.md` para as instruções completas do projeto.

### Resumo Executivo para Agentes:
1. **Sempre trabalhar orientado a Issues** (`[Correção]`, `[Melhoria]`, `[Nova função]`).
2. **Sempre documentar entregas no padrão de Pull Request**:
   - Issue relacionada;
   - O que mudou;
   - Como foi validado;
   - Riscos e limitações;
   - Próximos passos.
3. **Validar código sempre** via linter (`tsc --noEmit`) e compilação de build antes de concluir.
